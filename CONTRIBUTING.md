# Contributing

Thanks for wanting to help! Fixes, improvements and ideas are all welcome.

## Reporting a bug or asking for a feature

Open an Issue and include:
- what you did, what you expected, and what happened instead
- which app, and whether it was in a browser, the Android app, the Windows app or an iPhone
- anything from `sudo docker logs <container-name>` that looks like an error

## Sending a fix

1. Fork the repository and make your change.
2. Keep it focused: one fix or feature per pull request.
3. Test it on a server (a spare VM is perfect) by running `sudo bash install.sh` from your copy.
4. Open a pull request describing what changed and why.

Small fixes (bugs, typos, clearer guide steps) can go straight to a pull request. For bigger changes or new features, open an Issue first so we can agree on the approach.

## Ground rules

Be kind and patient. Everyone here is running this at home for their own family, and many are new to self-hosting.
